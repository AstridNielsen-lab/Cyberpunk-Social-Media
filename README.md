# manipulations

![manipulations preview](https://images.unsplash.com/photo-1515630278258-407f66498911?q=80&w=1200&auto=format&fit=crop)

**manipulations** é uma rede social minimalista para expressar seu microcosmo digital, criada com um design cyberpunk único e funcionalidades intuitivas.

## 🌟 Características

- **Timeline Infinita**: Posts organizados cronologicamente
- **Editor de Posts**: Suporte para texto, imagens e vídeos
- **Design Cyberpunk**: Interface moderna com tema matrix
- **Armazenamento Local**: Seus posts são salvos no navegador
- **Responsivo**: Funciona em qualquer dispositivo

## 🚀 Como Usar

1. **Criar um Post**
   - Clique no botão '+' no canto inferior direito
   - Digite sua mensagem
   - Adicione imagens ou URLs de vídeo (opcional)
   - Clique em "Publicar"

2. **Visualizar Posts**
   - Scroll pela timeline para ver posts anteriores
   - Os posts mais recentes aparecem no topo
   - Até 100 posts são mantidos no histórico

3. **Reset da Timeline**
   - Pressione Shift + Clique triplo no botão '+'
   - Isso limpará todos os posts (use com cuidado!)

## 💻 Tecnologias

- React
- TypeScript
- Tailwind CSS
- Vite
- Local Storage para persistência

## 🔒 Privacidade

Seus dados são armazenados apenas localmente no seu navegador. Não há servidor central ou coleta de dados.
